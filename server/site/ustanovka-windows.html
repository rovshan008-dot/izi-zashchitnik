Как установить на компьютер с Windows

Шесть шагов, около трёх минут. Для Windows 10 и 11.

Эта страница для компьютера. Откройте её на компьютере с Windows. Для телефона Android есть своя инструкция.
Windows покажет одно-два предупреждения — это нормально. Так она реагирует на любую программу, которая не куплена в магазине Microsoft. Ниже показано, что нажимать.

  • 2Запустить
  • 3Разрешить
  • 4Установить
  • 5Добавить
  • 6Включить
1

Скачайте программу

Нажмите зелёную кнопку. Файл весит .

Скачать для Windows

Браузер Edge может придержать файл. Справа вверху появится значок загрузок с жёлтым треугольником. Нажмите его, у файла нажмите … → Сохранить, затем Показать больше → Всё равно сохранить.

В Chrome: у загрузки нажмите Сохранить или Всё равно скачать.

2

Запустите скачанный файл

Нажмите на файл в списке загрузок браузера. Или откройте папку Загрузки и дважды нажмите на izi-zashchitnik-windows.exe.

Появится синее окно «Система Windows защитила ваш компьютер»:

  1. Нажмите ссылку Подробнее.
  2. Нажмите кнопку Выполнить в любом случае.

Кнопка «Выполнить в любом случае» появляется после нажатия «Подробнее».

3

Разрешите изменения

Windows спросит: «Разрешить этому приложению вносить изменения на вашем устройстве?» Нажмите Да.

ДаНет

Если Windows попросит пароль, введите пароль от этого компьютера.

4

Установите

Откроется установщик. Нажмите Далее, потом Готово. Галочку «Запустить „Изи Защитник“» оставьте — программа откроется сама.

На рабочем столе появится значок — зелёный щит «Изи Защитник».

5

Добавьте подключение

  1. В программе нажмите кнопку Добавить. Ваше подключение появится само: ссылка скопировалась, когда вы нажимали «Скачать».
  2. Скопируйте ссылку, которую вам прислали. Потом в программе нажмите кнопку Добавить — ссылка подставится сама.

Подключение не появилось? Нажмите одну из кнопок ниже, когда программа уже установлена.

Добавить подключение в программу

Ссылка скопирована. Откройте «Изи Защитник» и нажмите «Добавить».

6

Включите защиту

Нажмите большую круглую кнопку Включить. Через несколько секунд она станет зелёной, под ней появится «Защита включена».

Готово

Чтобы выключить, нажмите ту же кнопку. Пока защита включена, крестик сворачивает окно, а не закрывает его.

Если что-то пошло не так

При каждом запуске Windows спрашивает «Разрешить изменения?»

Так и должно быть: программе нужны права администратора, чтобы защищать весь компьютер, а не только браузер. Нажимайте «Да».

Файл не скачивается или называется .crdownload

Загрузка не закончилась: браузер ждёт вашего разрешения. Откройте список загрузок браузера (значок со стрелкой справа вверху) и выберите «Сохранить» → «Всё равно сохранить». Недокачанный файл .crdownload можно удалить.

Антивирус удалил файл или не даёт запустить

Так бывает с новыми программами без платной подписи. Скачивайте файл только с этой страницы. Если антивирус удалил его, добавьте файл в исключения антивируса и скачайте ещё раз.

Нажал «Включить», а программа пишет ошибку

Выключите на компьютере другие похожие программы (другие VPN, прокси) и попробуйте ещё раз. Если не помогло, в программе нажмите «Для мастера» → «Журнал работы» и пришлите нам текст оттуда.

Защита включена, но сайты не открываются

Нажмите строку «Сервер» под большой кнопкой и выберите другой сервер. Если не помогло, выключите и снова включите защиту.

Компьютер на процессоре ARM (Surface, Windows на Маке)

Для таких компьютеров есть отдельная версия: скачать для ARM. Узнать процессор: «Параметры» → «Система» → «О системе», строка «Тип системы».

Не получилось? Напишите нам: кнопка «Поддержка» есть на главной странице.
