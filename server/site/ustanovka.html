Изи Защитник

Приложение для телефонов на Android. Установка занимает пару минут.

Похоже, у вас iPhone. Это приложение только для Android — для iPhone вернитесь назад и выберите другой способ подключения.
1

Скачайте приложение

Скачать ()

Если телефон спросит, можно ли скачать этот файл, — разрешите.

2

Установите

Откройте скачанный файл (он появится в уведомлениях или в «Загрузках») и нажмите «Установить».

Телефон может попросить разрешить установку из браузера — включите переключатель и вернитесь назад. Если появится предупреждение о неизвестном приложении, выберите «Всё равно установить».

3

Добавьте подключение

Откройте «Изи Защитник» и нажмите «Добавить» — ваше подключение появится само.

Скопируйте ссылку, которую вам прислали, откройте «Изи Защитник» и нажмите «Добавить».

Не появилось? Нажмите кнопку ниже, когда приложение уже установлено.

Добавить подключение
4

Включите

Нажмите большую кнопку «Включить». Телефон один раз спросит разрешение на подключение — согласитесь.
