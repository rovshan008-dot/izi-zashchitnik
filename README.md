# Изи Защитник

Android-клиент экосистемы IZI. Основан на [sing-box for Android](https://github.com/SagerNet/sing-box-for-android)
(коммит `f87c2ebd`, версия 1.14.4) и ядре [sing-box](https://github.com/SagerNet/sing-box) v1.14.4.

Это отдельное приложение. Оно не связано с проектом sing-box и его авторами и не использует их название.

## Лицензия

GPL-3.0-or-later, как у исходного проекта (файл `LICENSE`). Исходный README сохранён в `UPSTREAM_README.md`.

## Что изменено относительно исходного проекта

- имя приложения, идентификатор (`tech.izi20.zashchitnik`) и значок;
- сборка только под ARM (телефоны, планшеты, ТВ-приставки);
- проверка обновлений смотрит на этот репозиторий;
- удалён ключ подписи исходного проекта, сборка идёт своим ключом;
- простой главный экран: одна кнопка «Включить», одна кнопка «Добавить» (ссылка берётся из буфера обмена),
  список подключений для переключения; прежние экраны собраны в разделе «Для мастера»;
- добавление по кнопке с сайта: ссылка `izi-zashchitnik://add?url=<ссылка>&name=<название>`
  (готовая страница с кнопкой — `server/site/dobavit.html`).

Полный список — в истории коммитов: первый коммит после README содержит исходники без изменений.

## Сборка

Сборка идёт в GitHub Actions (`.github/workflows/build.yml`): из исходников sing-box собирается ядро `libbox`,
затем APK. Готовые пробные сборки лежат в разделе Releases.

Номер сборки — `VERSION_CODE` в `version.properties`. На один номер выкладывается одна сборка (`build-<номер>`),
для следующей номер нужно увеличить.

Чтобы новая сборка ставилась поверх старой, нужен постоянный ключ подписи в секретах репозитория:
`KEYSTORE_B64` (файл ключа в base64) и `LOCAL_PROPERTIES` (base64 от строк `KEYSTORE_PASS=…`, `ALIAS_NAME=…`,
`ALIAS_PASS=…`). Без них сборка подписывается одноразовым отладочным ключом и поверх предыдущей не установится.
